# BetterSteamAuth

A Steam Guard desktop authenticator for Windows, with its own connection and proxy for each account.

## Build

Requires the .NET 10 SDK.

```bash
dotnet build
dotnet test
dotnet run --project src/BetterSteamAuth.App
```
